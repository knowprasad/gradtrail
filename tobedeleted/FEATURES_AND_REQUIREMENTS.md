# Northstar: what it does and what it needs

Northstar is a self-hosted workspace for managing one person’s job search. It keeps a career profile, finds jobs, prepares application materials, and tracks applications.

## What you can do

| Area | Features |
|---|---|
| **Profile** | Store skills, languages, work history, projects, education, publications, and references. Import a profile from PDF, Word, or Markdown. |
| **Resumes** | Build a base resume, choose or customize themes, preview changes, and export PDFs. Tailor a resume to each posting. |
| **Find jobs** | Search with JSearch, Adzuna, FreeHire, or the unofficial Germany-only Arbeitsagentur source. Save, dismiss, score, and apply from postings. |
| **Startups** | Browse hiring startups from YC and Hacker News. Results are filtered for location and ranked against your profile. Site reads follow robots.txt. |
| **Job agent (optional)** | Run a daily search, score new postings, explain scores, and prepare drafts. Drafts wait for your approval; the agent does not send applications. |
| **Applications** | Create an application from a posting. Generate a tailored resume, cover letter, and email. Refine drafts in chat, edit sections, undo changes, and revisit versions. |
| **AI safeguards** | By default, generated experience is checked against profile and posting facts. Missing qualifications appear as gaps rather than invented experience. |
| **Tracking** | View applications in a board or table. Track status history, trends, next actions, interviews, and calendar events. |
| **Gmail and Calendar (optional)** | Send application mail from Gmail, view employer replies, draft responses, find free interview times, and sync interviews with Google Calendar. Sending requires confirmation. |
| **Claude connector (optional)** | Let Claude search and score jobs, read profile/application data, and save checked drafts. It cannot send or delete. |
| **Your data** | Export and restore your data, download all PDFs, create nightly backups, or delete your data. |

## What you need

### Required

| Requirement | Details |
|---|---|
| PostgreSQL | Provide a connection string in `DATABASE_URL`. |
| Sign-in password | Set `NORTHSTAR_PASSWORD` to a password hash generated by the `hash-password` command. Do not put the plain password here. |
| Encryption/session secret | Set `NORTHSTAR_SECRET` to at least 32 random characters. Changing it signs you out and makes saved encrypted credentials unreadable until entered again. |
| Runtime | Docker Compose is the documented deployment path. PDF generation uses Chromium inside the app container. |
| Single instance | Run one app instance per database. Background jobs, PDF rendering, the job-agent schedule, and nightly backups run inside the app process. |

See `.env.example` and `DEVELOPMENT.md` for setup commands.

### Optional integrations

| Feature | Setup |
|---|---|
| AI writing | Choose a provider in Settings or set `NORTHSTAR_AI_*`. Supported options: Ollama/llama.cpp, LM Studio, Anthropic, Mistral, and OpenAI-compatible services. Hosted providers need a key; local providers need a reachable model server. |
| Job search | JSearch needs an OpenWeb Ninja or RapidAPI key. Adzuna needs an app ID and key. FreeHire needs no key. Arbeitsagentur is unofficial, Germany-only, subject to terms/consent limits, and excluded from the job agent. |
| Google | Create an OAuth web client; enable Gmail and Calendar APIs; configure `/api/google/callback`. Enter credentials in Settings or use `NORTHSTAR_GOOGLE_CLIENT_ID` and `NORTHSTAR_GOOGLE_CLIENT_SECRET`. |
| Public URL | Set `NORTHSTAR_PUBLIC_URL` if the browser-visible address differs from the address Northstar detects. This is used for Google redirects. |
| Claude | Enable the connector in Settings. Claude-hosted clients need a public HTTPS address. |
| Usage ping | By default, production asks for consent after sign-in and sends nothing before consent. `NORTHSTAR_TELEMETRY=on` or `off` records a choice in advance. |

## Limits to know about

- Northstar is designed for one user. It has no accounts or multi-tenant access.
- Nightly app backups do not replace PostgreSQL backups. Back up the database separately.
- Import files are limited to 10 MB.
- PDF rendering uses Chromium. The README recommends at least 768 MB of container memory.
- JSearch and Adzuna may use provider quota. Job search results are cached in memory for 30 minutes.
- AI services receive the prompt data needed for each task. See `PRIVACY.md` for details about AI, Google, Claude, startup site access, and usage ping.
